> [!NOTE]
> This page is automatically generated. It compares the features across different FFmpeg versions and highlights the support status of the precompiled packages.
> 
> - **Regular Text** (e.g. `aac`, `bluray`): Feature is **supported and enabled** in the precompiled package.
> - **Strikethrough** (e.g. ~~aac_fixed~~, ~~libssh~~): Feature exists in that FFmpeg version codebase, but is **disabled** in the precompiled package.
> - **Blank**: Feature does not exist in that FFmpeg version.
> - **Header Numbers** (e.g. `8.1.2 (232/608)`): `(Enabled Features / Total Available Features)` for that category.
> - **`Android 8.1.2` / `HarmonyOS 8.1.2`**: the same 8.1.2 source, but the enable/disable state is read from the Android / HarmonyOS precompiled package. So e.g. `h264_mediacodec` is enabled on Android and disabled on macOS, while `*_videotoolbox` is the other way around.
