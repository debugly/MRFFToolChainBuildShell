# 🌈 FFmpeg Virtual Test Sources Showcase

[← Back to Portal](index.html)

This dedicated page showcases all the built-in virtual test video and audio sources compiled within our custom-built **FFmpeg 8-bin**. These source filters can be loaded dynamically via the `lavfi` input device to generate colors, shapes, noise, charts, and mathematical patterns without needing external files!

> 🔊 Every sample carries a 1 kHz **sync beep at the start of each second** (100 ms, -18 dBFS). It functions as an A/V-offset marker: the beep must land exactly on the second of the picture, and a missing or doubled beep means dropped audio.

## 4. Reference Test Cards (calibration material)

These four cards are not built-in sources: they are composed from `drawbox`, `gradients`,
`smptehdbars` and `drawtext` by `tools/portal-site/generate-test-videos.sh`. They render at
**1920×1080** and are meant for spotting colour error, banding, overscan and frame pacing on a real
display or player.

### 🎨 Calibration Colour Chart (`drawbox` + `gradients`)

8 × 6 patch matrix (primaries, 75 % bars, grey ladder, skin tones, saturated ramps, IRE steps) over a
continuous black→white ramp plus an 11-step strip, with overscan brackets and a centre cross. Every
second the whole card **inverts** (`negate` on a timeline expression), so a frozen frame stands out even
on a static colour chart — the picture keeps changing while the stream is alive.

```bash
# abbreviated (two patches + ramp): the full matrix is generated by generate-test-videos.sh
ffmpeg -f lavfi -i "color=c=black:s=1920x1080:r=30" \
       -f lavfi -i "gradients=s=1920x126:r=30:c0=black:c1=white:x0=0:y0=0:x1=1919:y1=0:type=linear" \
       -filter_complex "[0:v]drawbox=x=0:y=0:w=240:h=150:color=0xffffff:t=fill,drawbox=x=240:y=0:w=240:h=150:color=0xffff00:t=fill[patches];[patches][1:v]overlay=0:900[cat];[cat]negate=enable='eq(mod(floor(t)\,2)\,1)'[out]" \
       -map "[out]" -t 5 -pix_fmt yuv420p -c:v libx264 card_colorchart.mp4
```

### 🌗 Black→White Banding Ramp (`gradients`)

One smooth 0→255 sweep across the frame. Visible steps mean 8-bit banding in the display, the player's
scaler, or the encoder.

```bash
ffmpeg -f lavfi -i "gradients=s=1920x1080:r=30:c0=black:c1=white:x0=0:y0=0:x1=1919:y1=0:type=linear" -t 5 -pix_fmt yuv420p -c:v libx264 card_ramp.mp4
```

### 🔢 Frame Counter 60 fps (dropped frames / stutter / seek)

Every frame is numbered with its timecode over a background that changes tint every second, with a red
progress bar that fills across the clip. A repeated number or a tint that stops changing is a frozen
frame, a skipped number is a dropped frame, and after a seek the number must match the timecode.
Numbers need the `drawtext` filter; builds without it (freetype is optional) show the frame number as
eight binary boxes instead.

```bash
ffmpeg -f lavfi -i "color=c=0x141414:s=1920x1080:r=60" \
       -f lavfi -i "color=c=0xff3c3c:s=1920x12:r=60" -t 5 -frames:v 300 \
  -filter_complex "[0:v]drawbox=x=0:y=0:w=iw:h=ih:color=0x141a22:t=fill:enable='eq(mod(floor(t)\,4)\,0)',drawbox=x=0:y=0:w=iw:h=ih:color=0x22141a:t=fill:enable='eq(mod(floor(t)\,4)\,1)',drawbox=x=0:y=0:w=iw:h=ih:color=0x14221a:t=fill:enable='eq(mod(floor(t)\,4)\,2)',drawbox=x=0:y=0:w=iw:h=ih:color=0x1e1e14:t=fill:enable='eq(mod(floor(t)\,4)\,3)',drawgrid=width=60:height=120:thickness=1:color=0x262c34,drawtext=fontfile=/System/Library/Fonts/Supplemental/Arial.ttf:text='%{n}':fontcolor=white:fontsize=300:x=(w-tw)/2:y=(h-th)/2,drawtext=fontfile=/System/Library/Fonts/Supplemental/Arial.ttf:text='%{pts\:hms}':fontcolor=0xffdc3c:fontsize=72:x=(w-tw)/2:y=h-200,drawtext=fontfile=/System/Library/Fonts/Supplemental/Arial.ttf:text='60 fps  frame %{n} / 299':fontcolor=0x969696:fontsize=40:x=40:y=40[base];[base][1:v]overlay=x='-overlay_w*(1-n/299)':y=1068:shortest=1[out]" \
  -map "[out]" -c:v libx264 -crf 18 -pix_fmt yuv420p card_framecounter.mp4
```

The progress bar is an `overlay` of a full-width red strip whose `x` expression pulls it in from the
left as `n` grows; `drawbox` geometry cannot do this, its `x`/`w` are evaluated once at start-up.
